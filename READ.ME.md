## Project Overview

This project implements sentiment classification on the MSCTD English-Chinese dialogue dataset using three progressively more complex approaches:

| # | Model | Architecture | Modality |
|---|-------|-------------|----------|
| 1 | **FullImageModel** | ResNet-50 (frozen backbone) + MLP head | Image only |
| 2 | **FusionModel** | ResNet-18 (faces via MTCNN) + FullImageModel + MLP fusion | Image + Face |
| 3 | **MultimodalTransformer** *(extra credit)* | ViT-B/16 + BERT-base + weighted fusion | Image + Text |

## Models

### 1. FullImageModel
- **Backbone:** ResNet-50 pretrained on ImageNet (all layers frozen)
- **Head:** Linear(2048, 512) → ReLU → Dropout(0.4) → Linear(512, 3)
- **Input:** Full conversation image (224×224)
- **Purpose:** Baseline — classifies sentiment from the whole image

### 2. FusionModel
- **Face detector:** MTCNN (Multi-task Cascaded CNN) via facenet-pytorch
- **Face encoder:** ResNet-18 with replaced classification head
- **Full image encoder:** FullImageModel (frozen)
- **Fusion input:** [face_probs(3) | full_probs(3) | num_faces_onehot(4)] = 10-dim
- **Head:** Linear(10, 512) → ReLU → Dropout(0.3) → Linear(512, 256) → ReLU → Linear(256, 3)
- **Purpose:** Combines facial expression signals with scene-level features

### 3. MultimodalTransformer *(Extra Credit)*
- **Vision encoder:** ViT-B/16 (`google/vit-base-patch16-224-in21k`) — 768-dim output
- **Text encoder:** BERT-base-uncased — 768-dim CLS output
- **Fusion:** Learnable weighted sum of vision and text features → 1536-dim concat
- **Head:** Linear(1536, 1024) → ReLU → Dropout(0.3) → Linear(1024, 512) → ReLU → Dropout(0.3) → Linear(512, 3)
- **Training:** AdamW, lr=2e-5, weight_decay=1e-4, 4 epochs
- **Purpose:** True multimodal fusion using state-of-the-art transformer encoders

## Known Limitations

- **No training images:** The MSCTD train split images are not available for public download via the notebook. Training loops are commented out; results are from ImageNet-initialised models only.
- **Free Colab quota:** Sessions may disconnect during long runs. Save checkpoints to Drive using `torch.save(model.state_dict(), '/content/drive/...')` after each epoch.
- **MultimodalTransformer** requires the English text split file (`english_train.txt` / `english_dev.txt`) in addition to images. Path must be set manually.
- MTCNN face detection adds significant per-sample overhead (~100ms/image on CPU). Use GPU for fusion dataset loading.
